# 快速入门指南 - 5分钟上手

## 🎯 目标
快速运行运动控制测试程序，观察梯形速度曲线和位置跟踪效果。

## 📋 前置条件检查

### 1. 检查 .NET 6.0 SDK
打开命令提示符，运行：
```cmd
dotnet --version
```
应该看到 `6.0.x` 或更高版本。如果没有，从这里下载：
https://dotnet.microsoft.com/download/dotnet/6.0

### 2. 检查 GCC 编译器
```cmd
gcc --version
```
如果提示命令不存在，需要安装 MSYS2：
1. 下载: https://www.msys2.org/
2. 安装后打开 MSYS2 终端
3. 运行: `pacman -S mingw-w64-x86_64-gcc`
4. 添加到PATH: `C:\msys64\mingw64\bin`

## 📊 理解图表

### 位置曲线（上图）
- **蓝色线**: 运动轴发出的**命令位置**（理想轨迹）
- **红色线**: 电机的**实际位置**（模拟反馈）
- **差距**: 就是"跟随误差"，PID增益越大，差距越小

### 速度曲线（中图）
- **梯形**: 加速段（斜坡上升）→ 匀速段（平台）→ 减速段（斜坡下降）
- **三角形**: 距离太短，未达到最大速度（无匀速段）

### 加速度曲线（下图）
- **正脉冲**: 加速段
- **零值**: 匀速段
- **负脉冲**: 减速段

## 🔧 常见问题

### Q: DLL加载失败？
**A**: 确保 `motion_control.dll` 在以下位置之一：
- `MotionAPI_Test\bin\Debug\net6.0-windows\`
- `motion_test\` 根目录

### Q: 图表不更新？
**A**: 检查：
1. 是否点击了 "使能轴"
2. 是否发送了运动命令
3. 仿真频率是否选择（默认1000Hz）

### Q: 速度曲线很尖锐，不平滑？
**A**: 这是正常的，因为：
1. 加速度是恒定的（梯形曲线）
2. 加速度曲线是阶跃的
3. 如需S曲线，需修改轨迹规划算法

### Q: 位置到达1000后继续飘移？
**A**: 调整PID参数：
1. 增大Kp（提高响应速度）
2. 增大Ki（消除稳态误差）
3. 增大Kd（抑制超调）
