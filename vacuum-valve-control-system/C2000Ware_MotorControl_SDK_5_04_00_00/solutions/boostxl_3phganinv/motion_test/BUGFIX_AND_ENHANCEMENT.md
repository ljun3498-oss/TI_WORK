## 📅 更新日期: 2025-12-31

## 🐛 Bug 修复

### 问题 1: 轴类型和电机数量显示错误

**现象**:
```
[02:00:07.451] 运动轴初始化成功
[02:00:07.465] 轴ID: 1, 类型: Virtual, 电机数量: 0
```

实际应该是：
- 类型: `Real`（实轴）
- 电机数量: `1`

**原因**:
在 `motion_control.c` 的 `MotionAxis_addMotor` 函数中，判断轴类型的逻辑有误：

```c
// 错误代码（第 662 行后）
axis->numMotors++;  // 先递增

// 更新轴类型
if(axis->numMotors == 0)  // ❌ 此时 numMotors 已经是 1，不可能等于 0
{
    axis->axisType = AXIS_TYPE_VIRTUAL;
}
else if(axis->numMotors >= 2)
{
    axis->axisType = AXIS_TYPE_GANTRY;
}
else
{
    axis->axisType = AXIS_TYPE_REAL;
}
```

**修复**:
调整判断逻辑，明确每种情况：

```c
// 修复后的代码
axis->numMotors++;  // 先递增

// 更新轴类型（在递增后判断）
if(axis->numMotors == 0)
{
    axis->axisType = AXIS_TYPE_VIRTUAL;  // 无电机=虚拟轴
}
else if(axis->numMotors == 1)           // ✅ 新增：明确判断单电机
{
    axis->axisType = AXIS_TYPE_REAL;     // 单电机=实轴
}
else // numMotors >= 2
{
    axis->axisType = AXIS_TYPE_GANTRY;   // 多电机=龙门轴
}
```

**验证**:
重新运行程序，日志应显示：
```
[HH:MM:SS] 运动轴初始化成功
[HH:MM:SS] 轴ID: 1, 类型: Real, 电机数量: 1  ✅
```

## ✨ 功能增强

### 增强 1: 实时状态显示优化

**需求**:
在绘制位置、速度、加速度曲线的同时，也实时刷新显示轴和下属电机的详细数值。

**改进内容**:

#### 1. 扩展显示区域

将原有的简单状态显示扩展为分层显示：

```
【运动轴】
  ├─ 轴状态
  ├─ 轴类型
  └─ 电机数量

【轴位置】
  ├─ 命令位置
  ├─ 实际位置
  └─ 位置误差

【轴速度】
  ├─ 命令速度
  └─ 实际速度

【轴加速度】
  └─ 当前加速度

【电机 #1】
  ├─ 使能状态
  ├─ 实际位置
  ├─ 实际速度
  └─ 错误计数
```

#### 2. UI 改进

**修改文件**: `MainWindow.xaml`

- 使用 `ScrollViewer` 支持更多内容显示
- 使用颜色区分不同类型的数据：
  - 🔵 **蓝色**: 命令值
  - 🔴 **红色**: 实际值
  - 🟣 **紫色**: 误差值
  - 🟠 **橙色**: 加速度
- 添加分隔线增强可读性
- 减小字体到 11pt 以容纳更多信息

#### 3. 数据更新

**修改文件**: `MainWindow.xaml.cs` → `UpdateStatusDisplay()`

新增显示项：

| 显示项 | 数据源 | 格式 |
|--------|--------|------|
| 轴类型 | `axis.axisType` | 枚举名称 |
| 电机数量 | `axis.numMotors` | 整数 |
| 轴命令位置 | `axis.cmdPosition` | 3位小数 |
| 轴实际位置 | `axis.actPosition` | 3位小数 |
| 轴位置误差 | `cmdPosition - actPosition` | 3位小数 |
| 轴命令速度 | `axis.cmdVelocity` | 2位小数 |
| 轴实际速度 | `axis.actVelocity` | 2位小数 |
| 轴加速度 | `Δvel / Δt` | 1位小数 |
| 电机使能状态 | `motors[0].enable` | 是/否 |
| 电机位置 | `motors[0].actPosition` | 3位小数 |
| 电机速度 | `motors[0].actVelocity` | 2位小数 |
| 电机错误计数 | `motors[0].errorCounter` | 整数 |

#### 4. 实时刷新

所有数据在 `PlotTimer_Tick` (50ms/20Hz) 中更新，确保：
- ✅ 与图表同步刷新
- ✅ 平滑显示，无闪烁
- ✅ 低 CPU 占用
