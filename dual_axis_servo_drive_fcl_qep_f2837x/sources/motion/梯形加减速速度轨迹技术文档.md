## 1. 概述

### 1.1 什么是梯形速度曲线

梯形速度曲线是运动控制中最基础、最常用的速度规划方式。其核心思想是通过控制加速度的**阶跃变化**来实现速度的线性升降，从而形成类似梯形的速度-时间曲线。

```
速度v
  ↑
  │        ┌─────────┐
  │        │         │ ← 匀速段 (CONST)
  │       /│         │\
  │      / │         │ \
vMax ─●─────┘         └──●───── vEnd
  │   ↑                   ↑
  │accelEndPos        decelStartPos
  │
  └──────────────────────────────→ 时间
     accelTime   constTime  decelTime
```

### 1.2 模块位置

```
f2837x_cpu1/source/
├── motion_control.c    ← 梯形曲线主实现
└── motion_control.h    ← 数据结构与API定义
```

### 1.3 核心特性

| 特性 | 说明 |
|------|------|
| **加速度** | 阶跃变化（从0瞬间跳变到设定值） |
| **计算复杂度** | 低，适合实时控制 |
| **控制精度** | 中等 |
| **机械冲击** | 较大（加速度突变） |
| **适用场景** | 一般运动控制、对振动要求不高的场合 |

### 1.4 jerkTime参数

梯形曲线通过`jerkTime = 0`来区分：

```c
// motion_control.c 第138行
if(profile->jerkTime > 0.0001f)
{
    // 使用S型曲线
    TrapProfile_computeSCurve(profile);
}
else
{
    // 使用梯形曲线（默认）
    // ...
}
```

## 2. 基本概念与数学基础

### 2.1 核心参数

| 参数 | 符号 | 定义 | 单位 |
|------|-------|------|------|
| 最大速度 | vMax | 运动过程中允许的最大速度 | unit/s |
| 最大加速度 | aMax | 加速阶段的最大加速度 | unit/s² |
| 最大减速度 | dMax | 减速阶段的最大减速度 | unit/s² |
| 起始速度 | vStart | 轨迹开始时的速度（带符号） | unit/s |
| 目标速度 | vEnd | 轨迹结束时的速度（通常为0） | unit/s |
| 当前速度 | vCurrent | 当前位置对应的速度 | unit/s |
| 当前位置 | currentPos | 轨迹计算时的起点 | unit |
| 目标位置 | targetPos | 运动的目标位置 | unit |
| 运动距离 | distance | currentPos → targetPos 的距离 | unit |

### 2.2 运动学公式

#### 速度-时间关系

```
匀加速运动：  v(t) = v₀ + a × t
匀减速运动：  v(t) = v₀ - d × t
```

#### 位移-时间关系

```
匀加速：  s(t) = v₀ × t + 0.5 × a × t²
匀减速：  s(t) = v₀ × t - 0.5 × d × t²
```

#### 速度-位移关系

```
匀加速：  v² - v₀² = 2 × a × s
匀减速：  v² - v₀² = -2 × d × s
```

### 2.3 运动方向

代码中使用`speed`和`direction`两个概念：

- **speed（速率）**：始终为正值，表示运动快慢
- **direction（方向）**：+1 或 -1，表示运动方向

```c
// motion_control.c 第161行
distance = profile->targetPos - profile->currentPos;
direction = SIGN(distance);  // +1 或 -1
distance = ABS(distance);    // 取绝对值
```

### 3.3 急停支持

梯形曲线支持**急停功能**，通过`emergencyDecel`参数实现：

```c

if(profile->emergencyDecel > 0.1f)
{

else

}
```

## 4. 速度曲线分类

### 4.1 分类决策流程

```
                    ┌─────────────────────────┐
                    │ 计算距离和方向            │
                    │ distance = |targetPos -  │
                    │        currentPos|       │
                    └───────────┬─────────────┘
                                │
                                ↓
                    ┌─────────────────────────┐
                    │ vStart × direction < 0 ? │
                    │   (速度与目标方向相反?)   │
                    └───────────┬─────────────┘
                         是↙       ↘否
                        ┌────┐     ┌────┐
                        │反向│     │继续│
                        │运动│     │判断│
                        └────┘     └────┘
                                      │
                                      ↓
                          ┌─────────────────────────┐
                          │ vStart > vMax ?         │
                          │  (当前速度超过最大速度?) │
                          └───────────┬─────────────┘
                               是↙       ↘否
                              ┌────┐     ┌────┐
                              │减速│     │继续│
                              │型  │     │判断│
                              └────┘     └────┘
                                            │
                                            ↓
                                ┌─────────────────────────┐
                                │ vStart < vMax - 0.01 ?  │
                                │   (需要加速?)            │
                                └───────────┬─────────────┘
                                     是↙       ↘否
                                    ┌────┐     ┌────┐
                                    │加速│     │匀速│
                                    │型  │     │/停 │
                                    └────┘     └────┘
```

### 4.2 四种轨迹类型

#### 类型1：纯减速型（Pure Deceleration）

**条件**：`vStart > vMax` 且距离足够

```
速度v
  ↑
  │500 ●━━━━━━━━━━━━━━━━━━━━━━━━┐
  │     ╲                        ╲
  │      ╲ (Phase A: 减速)        ╲
  │       ╲                        ╲
  │300    ━━━━━━━━━●━━━━━━━━━━━━━━━┛
  │        ←Phase B: 匀速→←Phase C: 减速
  └────────────────────────────────────→ 位置
```

**特点**：
- 起始速度高于最大允许速度
- 需要先减速到vMax
- 然后匀速，最后减速到vEnd

#### 类型2：三角形型（Triangular）

**条件**：`accelDist + decelDist > distance`

```
速度v
  ↑
  │     ●
  │    ╱ ╲
  │   ╱   ╲
  │  ╱     ╲
  │ ●───────●
  │           
  └────────────────────→ 位置
     加速   减速
```

**特点**：
- 距离不足以达到匀速段
- 速度曲线呈三角形
- 需要计算峰值速度 vPeak

#### 类型3：梯形型（Trapezoidal）

**条件**：`accelDist + decelDist ≤ distance`

```
速度v
  ↑
  │       ┌────┐
  │      /│    │\
  │     / │    │ \
  │    ●  │    │  ●
  │        └────┘
  └────────────────────→ 位置
     加速 匀速 减速
```

**特点**：
- 标准梯形曲线
- 有完整的加速、匀速、减速段
- 最常见的速度曲线类型

#### 类型4：纯匀速/纯停止型（Constant/Stop）

**条件**：`vStart ≈ vMax` 且 `decelDist = distance`

```
速度v
  ↑
  │━━━━━━━━━━━━━●
  │              ↑
  │           vEnd
  └────────────────────→ 位置
          匀速/减速
```

### 4.3 分类条件速查

| 类型 | 速度关系 | 距离条件 | 匀速段 |
|------|----------|----------|--------|
| **纯减速** | `vStart > vMax` | 距离足够 | 有 |
| **三角形** | `vStart < vMax` | `accelDist + decelDist > distance` | 无 |
| **梯形** | `vStart < vMax` | `accelDist + decelDist ≤ distance` | 有 |
| **纯匀速** | `vStart ≈ vMax` | `decelDist = distance` | 有（很长） |

## 5. 轨迹规划原理

### 5.1 主函数：TrapProfile_compute()


**执行流程**：

```
1. 读取输入参数
   ↓
2. 计算运动距离和方向
   ↓
3. 确定有效减速度（急停/普通）
   ↓
4. 处理速度变化（vStart > vMax）
   ↓
5. 处理反向运动（速度方向相反）
   ↓
6. 分类计算各段距离
   ↓
7. 计算各段时间
   ↓
8. 计算位置点
   ↓
9. 保存轨迹参数
```

### 5.2 距离计算

#### 加速/减速距离公式

```c
// motion_control.c 第238-240行

// 加速段距离（可用于加速或减速）
// 当 vStart > vMax 时，accelDist < 0（表示减速）
accelDist = (vMax² - vStart²) / (2 × actualAccel);

// 减速段距离
decelDist = (vMax² - vEnd²) / (2 × actualDecel);

// 匀速段距离
constDist = distance - ABS(accelDist) - decelDist;
```

**物理意义**：
- 加速：速度增加，动能增加，需要消耗距离
- 减速：速度降低，动能减少，可以回收距离

### 5.3 时间计算

```c
// motion_control.c 第366-370行

// 【关键修复】：accelTime 应该取绝对值
profile->accelTime = (vMax - vStart) / profile->actualAccel;
profile->accelTime = ABS(profile->accelTime);

// 匀速段时间
profile->constTime = constDist / (vMax > 0 ? vMax : 1.0f);

// 减速段时间
profile->decelTime = ABS(vMax - vEnd) / profile->actualDecel;

// 总时间
profile->totalTime = reverseDecelTime + accelTime + constTime + decelTime;
```

### 5.4 位置点计算

```c
// motion_control.c 第386-403行

// 反向减速结束位置
profile->reverseDecelEndPos = profile->currentPos + vStart × stopTime × 0.5f;

// 加速结束位置（特殊处理 accelDist < 0 的情况）
if(accelDist < 0.0f)
{
    // 减速型：向运动方向走 ABS(accelDist) 的距离
    profile->accelEndPos = profile->reverseDecelEndPos + direction × ABS(accelDist);
}
else
{
    // 加速型：正常计算
    profile->accelEndPos = profile->reverseDecelEndPos + direction × accelDist;
}

// 减速开始位置
profile->decelStartPos = profile->accelEndPos + direction × constDist;
```

### 5.5 三角形轨迹计算

当距离不足以匀速时，需要计算三角形轨迹的峰值速度：

```c
// motion_control.c 第327-330行

// 求解二次方程得到峰值速度
// s_total = (vStart² - vPeak²)/(2×J) + (vPeak² - vEnd²)/(2×K)
// 整理后得：
vPeak = sqrt((2 × accel × decel × distance + 
              decel × vStart² + 
              accel × vEnd²) / 
             (accel + decel));
```

## 6. 速度分段计算

### 6.1 梯形曲线四阶段

```
Phase 0: 反向减速段（如果需要）
Phase 1: 加速段（或减速型中的减速段）
Phase 2: 匀速段
Phase 3: 减速段
```

### 6.2 位置计算：TrapProfile_getPosition()

```c
// motion_control.c 第437-581行
float32_t TrapProfile_getPosition(TrapezoidalProfile_t *profile, float32_t dt)
{
    // 1. 更新已用时间
    profile->elapsedTime += dt;
    t = profile->elapsedTime;
    
    // 2. 计算有效减速度
    effectiveDecel = (emergencyDecel > 0.1f) ? emergencyDecel : actualDecel;
    
    // 3. 判断所处阶段
    if(t <= reverseDecelTime)
    {
        // ===== Phase 0: 反向减速段 =====
        // 速度方向与目标方向相反，先减速到0
        position = startPos + v0 × t - 0.5 × decel × t² × direction;
    }
    else
    {
        t_adj = t - reverseDecelTime;
        
        if(t_adj <= accelTime)
        {
            // ===== Phase 1: 加速段/减速型减速段 =====
            if(accelDist < 0.0f)
            {
                // 减速型：v(t) = vStart - decel×t
                position = reverseDecelEndPos + 
                         (vStart × t_adj - 0.5 × decel × t_adj²) × direction;
            }
            else
            {
                // 加速型：v(t) = vStart + accel×t
                position = reverseDecelEndPos + 
                         (vStart × t_adj + 0.5 × accel × t_adj²) × direction;
            }
        }
        else if(t_adj <= accelTime + constTime)
        {
            // ===== Phase 2: 匀速段 =====
            t1 = t_adj - accelTime;
            position = accelEndPos + vMax × t1 × direction;
        }
        else if(t_adj <= accelTime + constTime + decelTime)
        {
            // ===== Phase 3: 减速段 =====
            t2 = t_adj - accelTime - constTime;
            position = decelStartPos + 
                     (vMax × t2 - 0.5 × decel × t2²) × direction;
        }
        else
        {
            // ===== 运动完成 =====
            profile->state = PROFILE_DONE;
            profile->isActive = false;
            position = targetPos;
        }
    }
    
    return position;
}
```

### 6.3 速度计算：TrapProfile_getVelocity()

```c
// motion_control.c 第602-691行
float32_t TrapProfile_getVelocity(TrapezoidalProfile_t *profile)
{
    t = profile->elapsedTime;
    effectiveDecel = (emergencyDecel > 0.1f) ? emergencyDecel : actualDecel;
    
    if(t <= reverseDecelTime)
    {
        // 反向减速段
        velocity = initialVel - effectiveDecel × t × direction;
    }
    else
    {
        t_adj = t - reverseDecelTime;
        
        // 特殊处理：纯减速轨迹
        if(accelTime == 0.0f && constTime == 0.0f)
        {
            if(t_adj <= decelTime)
                velocity = (vStart - effectiveDecel × t_adj) × direction;
            else
                velocity = 0.0f;
        }
        else if(t_adj <= accelTime)
        {
            // 加速段/减速型减速段
            if(accelDist < 0.0f)
                velocity = (vStart - effectiveDecel × t_adj) × direction;
            else
                velocity = (vStart + accel × t_adj) × direction;
        }
        else if(t_adj <= accelTime + constTime)
        {
            // 匀速段
            velocity = vMax × direction;
        }
        else if(t_adj <= accelTime + constTime + decelTime)
        {
            // 减速段
            t2 = t_adj - accelTime - constTime;
            velocity = (vMax - effectiveDecel × t2) × direction;
        }
        else
        {
            velocity = 0.0f;
        }
    }
    
    return velocity;
}
```

### 6.4 加速度计算：TrapProfile_getAcceleration()

```c
// motion_control.c 第696-800行
float32_t TrapProfile_getAcceleration(TrapezoidalProfile_t *profile)
{
    if(!profile->isActive) return 0.0f;
    
    // 梯形曲线加速度为常数（跳变）
    if(profile->state == PROFILE_ACCEL)
        return actualAccel × direction;
    else if(profile->state == PROFILE_DECEL)
        return -effectiveDecel × direction;
    else
        return 0.0f;  // 匀速段或完成
}
```

## 7. 特殊场景处理

### 7.1 反向运动处理

**场景**：当前速度方向与目标方向相反

```c
// motion_control.c 第211-233行

if(vStart × direction < 0)
{
    // 需要先减速到0
    stopTime = ABS(vStart) / actualDecel;
    stopDist = ABS(vStart) × stopTime × 0.5f;
    
    // 保存反向减速信息
    profile->reverseDecelTime = stopTime;
    profile->reverseDecelEndPos = profile->currentPos + vStart × stopTime × 0.5f;
    
    // 调整参数
    profile->currentPos = profile->reverseDecelEndPos;
    distance += stopDist;  // 需要额外距离停止
    vStart = 0.0f;  // 从0开始加速
}
```

**物理过程**：

```
时间0: v = -500, 位置 = 0
  ↓ 减速（方向不变）
时间T1: v = 0, 位置 = -125 (反向减速结束)
  ↓ 反向加速
时间T2: v = +300, 位置 = >0 (正常运动开始)
```

### 7.2 速度变化处理（减速→匀速→减速）

**场景**：`vStart > vMax`（运行中需要降低速度）

```c
// motion_control.c 第251-316行

if(vStart > vMax)
{
    // 【关键】accelDist 为负值！
    accelDist = (vMax² - vStart²) / (2 × accel);  // 负值
    
    s_needed = ABS(accelDist) + decelDist;
    
    if(s_needed > distance)
    {
        // 距离不够：退化为纯减速
        vPeak = sqrt(vStart² - 2 × accel × distance);
        vMax = vPeak;
        constDist = 0.0f;
    }
    else
    {
        // 距离足够：标准梯形
        constDist = distance - ABS(accelDist) - decelDist;
    }
}
```

**速度曲线**：

```
速度v
  ↑
  │500 ●━━━━━━━━━━━━━━━━━━━━━━━━┐
  │     ╲ (Phase A: 减速到vMax)   ╲
  │      ╲                        ╲
  │300    ━━━━━━━━●━━━━━━━━━━━━━━━┛
  │        ←Phase B: 匀速→←Phase C: 减速
  └──────────────────────────────────→ 位置
```

### 7.3 急停处理

**场景**：需要快速停止（如安全限位触发）

```c
// 使用 emergencyDecel（通常为 2× maxDecel）

if(profile->emergencyDecel > 0.1f)
{
    profile->actualDecel = profile->emergencyDecel;
    // 轨迹计算会使用更大的减速度
}
```

### 7.4 运动中更新目标

梯形曲线支持运动中更新目标位置：

```c
// motion_control.c 第103-116行
void TrapProfile_setTarget(TrapezoidalProfile_t *profile, 
                           float32_t currentPos, float32_t currentVel, 
                           float32_t targetPos)
{
    profile->currentPos = currentPos;
    profile->currentVel = currentVel;
    profile->targetPos = targetPos;
    
    // 保留速度的真实符号
    profile->startVelocity = currentVel;
    
    profile->isComputed = false;  // 需要重新计算
    profile->updateCounter++;
}
```

```c
typedef struct
{

    float32_t targetPos;          // 目标位置 [unit]

    float32_t accelTime;          // 加速时间 [s]

    float32_t decelTime;          // 减速时间 [s]
    float32_t totalTime;          // 总时间 [s]

    // ===== 位置点 =====
    float32_t reverseDecelEndPos; // 反向减速结束位置 [unit]
    float32_t accelEndPos;        // 加速结束位置 [unit]
    float32_t decelStartPos;      // 减速开始位置 [unit]

    // ===== 距离（带符号）=====
    float32_t accelDist;          // 加速距离（负值=减速）

    // ===== 实际运动参数 =====
    float32_t actualMaxVelocity;  // 实际最大速度 [unit/s]
    float32_t actualAccel;        // 实际加速度 [unit/s²]
    float32_t actualDecel;        // 实际减速度 [unit/s²]

    // ===== 配置快照 =====
    float32_t configuredMaxVel;    // 上次配置的最大速度
    float32_t configuredAccel;    // 上次配置的加速度
    float32_t configuredDecel;    // 上次配置的减速度

    // ===== 状态 =====
    ProfileState_e state;         // PROFILE_ACCEL/CONST/DECEL/DONE
    float32_t elapsedTime;        // 已运行时间 [s]
    uint32_t updateCounter;       // 更新计数器
    bool isComputed;              // 轨迹已计算
    bool isActive;                // 轨迹激活
    bool isEmergencyStop;           // 急停命令标志（区分急停和普通停止）
} TrapezoidalProfile_t;
```

## 10. 公式速查表

### 10.1 距离计算

| 公式 | 说明 |
|------|------|
| `accelDist = (vMax² - vStart²) / (2 × accel)` | 速度从vStart到vMax的加减距离 |
| `decelDist = (vMax² - vEnd²) / (2 × decel)` | 速度从vMax到vEnd的减速距离 |
| `constDist = distance - ABS(accelDist) - decelDist` | 匀速段距离 |
| `stopDist = vStart² / (2 × decel)` | 从vStart减速到0的距离 |

### 10.2 时间计算

| 公式 | 说明 |
|------|------|
| `accelTime = \|vMax - vStart\| / accel` | 加速/减速段时间 |
| `constTime = constDist / vMax` | 匀速段时间 |
| `decelTime = \|vMax - vEnd\| / decel` | 减速段时间 |
| `totalTime = reverseDecelTime + accelTime + constTime + decelTime` | 总时间 |

### 10.3 位置计算

| 阶段 | 公式 |
|------|------|
| 反向减速 | `pos = startPos + v0×t - 0.5×decel×t²` |
| 加速段 | `pos = accelEndPos + (vStart×t + 0.5×accel×t²)×dir` |
| 匀速段 | `pos = accelEndPos + vMax×(t-accelTime)×dir` |
| 减速段 | `pos = decelStartPos + (vMax×t - 0.5×decel×t²)×dir` |

### 10.4 速度计算

| 阶段 | 公式 |
|------|------|
| 反向减速 | `vel = v0 - decel×t` |
| 加速段 | `vel = vStart + accel×t` |
| 匀速段 | `vel = vMax` |
| 减速段 | `vel = vMax - decel×t` |

## 附录A：梯形与S型对比

| 特性 | 梯形曲线 | S型曲线 |
|------|----------|---------|
| **加速度** | 阶跃变化 | 线性变化 |
| **加加速度** | 突变（冲击力大） | 恒定（冲击小） |
| **jerkTime** | = 0 | > 0 |
| **速度曲线** | 梯形 | S形 |
| **计算复杂度** | 低 | 高 |
| **机械冲击** | 较大 | 较小 |
| **适用场景** | 一般运动 | 高精度/低振动 |
